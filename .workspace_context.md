# 📌 Workspace Context & Memory - Jump VPN

## 🚀 Project Overview
- **Name:** Jump VPN (Android App + Admin Web Panel + VPS Server Scripts)
- **Repository:** `https://github.com/Danieltest5230/jump-vpn.git` (branch `main`)
- **Goal:** Aplicación VPN para Android con soporte de inyección SSH/SSL/WebSocket CDN, túnel tun2socks seguro sin fugas de datos, y panel web administrativo con autogestión de usuarios en Render 24/7.
- **Tech Stack:**
  - **Mobile:** Android Nativo (Kotlin, Coroutines, VpnService, JSch SSH, tun2socks IP layer).
  - **Panel Web:** Node.js, Express, JWT, Bcrypt, Render Web Service.
  - **CI/CD:** GitHub Actions (`.github/workflows/build-apk.yml`).
  - **VPS Backend:** Scripts Bash (`server-scripts/setup_vps.sh`), Squid Proxy autenticado, Stunnel TLS (443), Python WebSocket bridge (80), BadVPN UDPGW (7300).

---

## ⚡ Active Services & Deployments
- **Render Web Service (Panel):** Activo en Render (Node.js runtime, build: `npm install`, start: `node server.js`).
  - Ruta de salud / Health Check: `/health` (Responde 200 OK y tiempo de actividad).
  - Portal de usuarios: `/cambiar-clave`

- **GitHub CI/CD:** GitHub Actions compilando APK automáticamente en cada tag/release.

## 🛠️ Environment & Setup
- **Panel Local (desarrollo):**
  - Comando: `cd panel && npm start`
  - Puerto local por defecto: `3000` (`http://localhost:3000`)
- **Variables de Entorno Clave:**
  - `RENDER_EXTERNAL_URL` o `APP_URL`: URL del panel en Render (usada para el auto-ping de 7 minutos).
  - `ADMIN_USER`: Usuario administrador del panel (ej. `admin`).
  - `ADMIN_PASS`: Contraseña del administrador del panel.
  - `JWT_SECRET`: Clave secreta para firma de tokens JWT.
- **Archivos Críticos del Proyecto:**
  - `android/app/src/main/java/com/jumpvpn/app/JumpVpnService.kt`: Servicio VPN Android, ruteo tun, captura IPv6 y protección de sockets.
  - `android/app/src/main/java/com/jumpvpn/app/Tun2Socks.kt`: Capa IP/UDP/TCP con proxy DNS protegido (evita fugas DNS).
  - `android/app/src/main/java/com/jumpvpn/app/SshTunnelClient.kt`: Conexión SSH segura con `setPortForwardingL`.
  - `android/app/src/main/java/com/jumpvpn/app/WebSocketTunnel.kt` & `SslSniSocket.kt`: Túneles WebSocket/SSL con lectura exacta de cabeceras HTTP.
  - `panel/server.js`: Servidor Express seguro, rate-limiting, `/health`, keep-alive anti-sleep.
  - `render.yaml` & `panel/render.yaml`: Blueprint y health check para Render.
  - `server-scripts/setup_vps.sh`: Script de aprovisionamiento del servidor Linux VPS.

## ✅ Completed Milestones & Fixes
- [x] **Auditoría y corrección de Fugas de Datos (Data Leaks):**
  - Ruteo IPv6 bloqueado (`fd00::2/120`, `::/0`) para impedir fugas por redes móviles IPv6.
  - DNS leak eliminado: implementado proxy DNS local hacia `1.1.1.1` mediante socket protegido en `Tun2Socks.kt`.
  - Bucle de ruteo resuelto (`JumpVpnService.protectSocket(...)` en sockets de túnel SSH, SSL y WS).
  - Bug de consumo de banner SSH en HTTP WebSocket solucionado (`readHeadersExact`).
  - Permisos invasivos eliminados de `AndroidManifest.xml` (geolocalización fina/gruesa, AD_ID).
- [x] **Seguridad en Panel Web:**
  - Vulnerabilidad de inyección de comandos en cambio de claves erradicada (se usa `spawn` seguro con stdin hacia `chpasswd`).
  - Rate limiting (5 intentos/minuto) implementado contra ataques de fuerza bruta en login y cambio de contraseña.
  - Secretos JWT robustos y cabeceras de seguridad HTTP (`X-Content-Type-Options`, `X-Frame-Options`, `X-XSS-Protection`).
- [x] **CI/CD en GitHub:**
  - Corregida firma de métodos JSch (`setPortForwardingL`).
  - Pipeline de GitHub Actions ejecutado con éxito produciendo `Jump-VPN-v4.6.2.apk`.
- [x] **Persistencia y Anti-Sleep 24/7 en Render:**
  - Endpoint `/health` implementado.
  - Sistema interno de auto-ping programado cada 7 minutos hacia la URL pública.
  - Archivos `render.yaml` creados con directiva `healthCheckPath: /health`.
  - Cambios sincronizados y pusheados a la rama `main` de GitHub.
